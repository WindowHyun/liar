## 남은 것

### D-3. 방을 나눌 것인가 **[설계 선택]**

Electron 버전은 같은 LAN이면 무조건 한 방이다. 사무실에서 두 팀이 동시에 하려면
방 코드가 필요하다. 웹 버전은 서버를 두 개 띄우면 되므로 해당 없다.

### E-3. 발견 프로토콜에 인증이 없다 **[코드]**

같은 LAN의 누구나 알림을 보낼 수 있고, `nodeId`를 작게 만들면 호스트를 가져갈 수 있다.
호스트는 라이어와 제시어를 정하므로 판 전체를 좌우한다. 사내 파티 게임이라면 감수할 수
있는 위험이지만, 막으려면 공유 비밀번호로 알림에 서명하는 정도면 충분하다.

**의도한 선택으로 남겨 둔다** — 필요해지면 그때 넣는다.

### E-5. macOS 창 닫기 관례 **[코드]**

`electron/main.js`의 `window-all-closed`가 플랫폼 구분 없이 종료한다. macOS는 창을 닫아도
앱이 살아 있는 것이 관례다. 지금 빌드 대상이 Windows뿐이라 미룬다.

### S-6. 대화를 매번 통째로 보낸다 **[설계]**

상태가 바뀔 때마다 최근 100개 대화가 전부 나간다. 인원이 10명 남짓인 지금은 이 단순함이
이득이다(어긋날 여지가 구조적으로 없다). 인원이 크게 늘면 증분으로 바꾼다.

### 그 밖에

- **exe 아이콘·서명 없음** — `npm run dist`는 되지만 기본 Electron 아이콘이 붙고 서명이 없어
  Windows SmartScreen 경고가 뜬다. 배포 규모에 따라 결정할 일이다.
- **자동 업데이트 없음** — 버전이 갈리면 E-2가 알려는 주지만, 새 파일을 다시 받는 건 수동이다.

## 실행

```bash
npm install
npm start          # Electron - 켜면 같은 네트워크에서 자동으로 모인다 (포트 55500)
npm run web        # 웹 - 한 사람만 켜고 나머지는 브라우저로 (포트 4100)
npm test           # 86건
npm run lint
npm run dist       # dist/Slack.exe
```
