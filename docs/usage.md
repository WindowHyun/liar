# 사용법

세 가지 방법이 있다. **처음이면 exe가 가장 쉽다.**

| 방법 | 누가 무엇을 하나 | 언제 쓰나 |
|---|---|---|
| **exe** | 각자 exe를 실행하면 끝 | 사무실에서 노트북끼리. 주소를 주고받을 필요가 없다 |
| **웹** | 한 사람이 서버를 켜고 주소를 알려준다 | 설치가 부담스럽거나, 폰으로 참여할 사람이 있을 때 |
| **모바일** | 웹 방식으로 켠 주소에 폰으로 접속 | 노트북이 없는 사람 |

최소 **2명**, 권장 4~6명.

---

## 1. exe 사용법

### 준비

1. [Releases](https://github.com/WindowHyun/liar/releases)에서 `liar-game-x.y.z-win-x64.exe`를 받는다.
2. **참가할 사람 전원이 같은 파일을 받는다.** 버전이 다르면 서로를 못 알아본다
   (다르면 화면에 "버전이 다릅니다"라고 뜬다).
3. 설치가 필요 없다. 받은 파일을 그냥 두 번 누르면 실행된다.

### 처음 실행할 때

- **Windows 방화벽 팝업이 뜨면 반드시 "허용"을 누른다.**
  취소하면 내 화면은 멀쩡한데 다른 사람에게는 내가 안 보인다. 가장 흔한 문제다.
  "개인 네트워크"에 체크되어 있으면 된다.
- SmartScreen이 "Windows의 PC 보호"를 띄우면 **자세히 → 실행**을 누른다.
  코드 서명을 하지 않아서 뜨는 경고다.

### 게임하기

1. 각자 exe를 실행한다. **주소를 입력할 필요가 없다** — 같은 네트워크에 있으면
   서로를 자동으로 찾는다. 잠깐 "같은 네트워크에서 함께할 참가자를 찾는 중"이 뜬다.
2. 닉네임을 넣고 접속한다.
3. 왼쪽에 참가자가 다 모이면 아무나 **게임 시작**을 누른다.

### 알아둘 것

- **아무나 시작 버튼을 눌러도 된다.** 누가 눌렀는지는 게임에 영향이 없다.
- 프로그램을 먼저 켠 사람의 PC가 진행 역할을 맡는다. 그 사람이 나가면 남은 사람 중
  하나가 자동으로 이어받는데, **진행 중이던 판은 처음부터 다시 시작**된다
  (화면에 이유가 뜬다).
- 프로그램을 껐다 켜도 닉네임은 기억한다.
- 같은 PC에서 두 번 실행해도 된다. 각각 다른 참가자로 들어간다.

### 잘 안 될 때

| 증상 | 확인할 것 |
|---|---|
| 나만 보이고 다른 사람이 안 보인다 | 방화벽 팝업에서 "허용"을 눌렀는지. 제어판 → Windows Defender 방화벽 → 앱 허용에서 확인 |
| 다른 사람은 서로 보이는데 나만 안 보인다 | 같은 Wi-Fi인지. 게스트 Wi-Fi는 기기 간 통신이 막혀 있는 경우가 많다 |
| "버전이 다릅니다"가 뜬다 | 전원이 같은 파일을 받았는지 |
| 회사 PC에서 안 붙는다 | 사내 프록시가 원인일 수 있다. 프로그램이 우회하도록 되어 있지만, 그래도 안 되면 아래 로그를 확인 |

로그 파일: `%TEMP%\liar-game.log` (탐색기 주소창에 `%TEMP%` 입력)

## 2. 웹 사용법

한 사람만 서버를 켜고, 나머지는 브라우저로 들어온다. Node.js 22 이상이 필요하다.

### 서버 켜는 사람

```bash
git clone https://github.com/WindowHyun/liar.git
cd liar
npm install
npm run web
```

띄우면 이렇게 나온다.

```
  라이어 게임 (웹 버전) 서버가 실행되었습니다.

  내 화면          : http://localhost:4100
  다른 참가자에게  : http://192.168.0.15:4100
```

**"다른 참가자에게" 주소를 사람들에게 알려주면 된다.** 방화벽 팝업이 뜨면 허용한다.

포트를 바꾸려면:

```bash
PORT=4200 npm run web        # macOS / Linux
set PORT=4200 && npm run web # Windows
```

### 참여하는 사람

브라우저에 받은 주소를 넣고, 닉네임을 입력하면 끝이다. 설치할 게 없다.

### 알아둘 것

- **서버를 켠 사람이 나가면 게임이 끝난다.** 그 PC가 서버이기 때문이다.
  exe 방식과 달리 자동으로 이어받지 않는다.
- 새로고침해도 자리와 진행 상황이 유지된다.
- 창을 여러 개 띄우면 각각 다른 참가자가 된다(테스트할 때 편하다).

## 3. 모바일 사용법

**폰만으로는 안 된다.** 누군가 PC에서 위 "웹 사용법"으로 서버를 켜야 한다.

1. 서버를 켠 사람에게 주소를 받는다 (`http://192.168.0.15:4100` 같은 형태).
2. **폰이 같은 Wi-Fi에 있어야 한다.** 셀룰러(LTE/5G)로는 안 된다.
3. 폰 브라우저에 주소를 입력한다. Chrome, Safari 모두 된다.
4. 닉네임을 넣고 접속한다.

### 폰 화면

- 참가자 목록이 위쪽에 가로로 접혀서 나오고, 아래가 대화창이다.
- 투표 찬반(O / X) 버튼은 손가락으로 누르기 좋게 세로로 크게 나온다.
- 홈 화면에 추가해 두면 다음에 주소를 다시 입력하지 않아도 된다
  (Safari: 공유 → 홈 화면에 추가 / Chrome: 메뉴 → 홈 화면에 추가).

### 잘 안 될 때

- 주소가 안 열린다 → 같은 Wi-Fi인지 확인. 회사 게스트 Wi-Fi는 기기 간 통신이
  막혀 있는 경우가 많다.
- 화면이 잘린다 → 브라우저를 세로로 두면 된다.

## 게임 규칙

1. 한 명이 **라이어**가 된다. 라이어만 제시어를 모른다(카테고리는 안다).
   - 시민 화면: `카테고리: 음식 / 제시어: 김치찌개`
   - 라이어 화면: `당신은 Oliveyoung입니다. 카테고리: 음식 (제시어는 모릅니다)`
2. **설명 차례가 랜덤으로 돌아간다.** 대화권을 받은 사람만 입력창이 열리고, 나머지는 잠긴다.
   - **대화권은 1인 1회**다. 한 번 말하면 그 자리에서 다음 사람에게 넘어간다.
   - 내 차례에는 입력창 테두리가 노랗게 바뀌고 `내 차례입니다`라고 알려 준다.
   - 60초 안에 말하지 않으면 넘어간 것으로 치고 다음 사람에게 간다.
   - 누가 설명을 마쳤는지는 ✅ / 🎙️ / ⏳ 로 한 줄에 보인다.
3. **전원이 한 번씩 말하면 자유 대화(1분)가 열린다.** 이때는 누구나 몇 번이든 말할 수 있다.
4. 라이어가 짐작되면 **🎧** 버튼을 누른다. 그러면 전원 화면에 **O / X**가 뜬다.
   - 🎧 버튼은 **자유 대화 때만** 눌린다. 설명이 끝나기 전에는 잠겨 있다.
   - **찬성이 절반 이상이면** 투표로 넘어간다. 4명 중 2명이 O여도 50%라 진행된다.
   - 반대가 절반을 넘으면 그 자리에서 부결되고 자유 대화로 돌아간다.
   - 아무도 누르지 않아도 자유 대화 1분이 지나면 찬반 없이 곧바로 투표로 간다.
5. 투표에서 가장 많이 지목된 사람이 공개된다.
   - **라이어가 아니면** → 라이어 승
   - **라이어면** → 라이어가 30초 안에 제시어를 맞히면 역전승, 못 맞히면 시민 승
   - 동점이거나 아무도 투표하지 않으면 라이어 승
6. 끝나면 라이어와 제시어가 전원에게 공개되고, 왼쪽에 전적이 쌓인다.

**찬반(O/X) 단계부터** 결과가 날 때까지 대화창이 잠긴다. 변론이 오가면 투표가 흐려지기
때문이다. 왜 잠겼는지는 입력창이 직접 알려 준다.

라운드 도중에 들어온 사람은 그 판을 **관전**하고 다음 판부터 참여한다.

### 나가기 / 튕겼을 때

- 왼쪽 아래 **방 나가기**를 누르면 그 자리에서 나간다. 자리를 남기지 않으므로 남은 사람이
  기다리지 않는다. 다시 들어오면 새 참가자로 들어간다.
- 창이 닫히거나 Wi-Fi가 끊기는 등 **뜻하지 않게 끊긴 경우에는 10초 동안 자리를 남긴다.**
  10초가 지나면 목록에서 지우지만, **그 뒤에 돌아와도 하던 자리로 이어서 한다.**
  (10초는 "남은 사람이 기다리는 시간"이지 "돌아올 수 있는 시한"이 아니다.)
- **라이어가 나가면 그 판은 취소된다.** 라이어 없이 계속해 봐야 아무도 라이어가 아니다.
  무승부로 접고 전적에 쌓지 않는다. 튕긴 경우에는 10초를 기다렸다가 접는다.
- 남은 참가자가 **2명보다 적어지면 그 판은 그 자리에서 취소**되고 로비로 돌아온다.
  사람이 다시 모이면 바로 다음 판을 시작할 수 있다.
