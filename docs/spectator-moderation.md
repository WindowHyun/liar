# 관전 모드와 다수결 강퇴

## 관전

- 입장 화면에서 **관전으로 입장**을 선택합니다. 게임 참가자는 최대 8명, 관전자는 별도로 최대 16명입니다.
- 관전자는 참가 인원·제시어·역할 배정·설명 순서·게임 투표에서 제외됩니다. 진행 중에는 채팅할 수 없고, 로비와 결과 화면에서는 대화할 수 있습니다.
- 사이드바의 **관전으로 전환 / 게임 참가로 전환** 버튼으로 변경합니다. 진행 중인 라운드의 참가자는 라운드가 끝나야 전환할 수 있습니다. 관전자가 게임 참가로 전환하면 다음 라운드부터 참여합니다.
- 새로고침·재접속 시 관전 상태를 유지합니다. 토큰은 탭별 sessionStorage에 저장하며 기존 공유 localStorage 토큰은 가져오지 않습니다. 새 탭은 별도 참가자입니다.

## 강퇴

- 접속 중인 게임 참가자가 참가자 목록의 **강퇴 제안**을 누릅니다. 관전자도 강퇴 대상이 될 수 있지만 제안·투표에는 참여하지 않습니다.
- 대상자를 제외한 접속 중 게임 참가자를 제안 시점에 확정합니다. 그 인원의 **과반수 찬성**이 필요하며, 최소 2명의 찬성이 필요합니다. 제안자의 찬성 1표는 자동으로 들어갑니다.
- 예: 대상 제외 3명 → 2표, 4명 → 3표. 두 사람만 있는 방에서는 서로 단독 강퇴할 수 없습니다.
- 투표는 30초 동안 진행됩니다. 동률·시간 초과는 부결입니다. 투표 도중 나가더라도 필요 찬성 수는 줄지 않으며, 새로 입장한 사람은 기존 투표에 참여하지 않습니다.
- 한 번에 한 건만 진행하고, 같은 참가자는 제안 후 30초 동안 다시 제안할 수 없습니다. 강퇴 투표는 게임 단계와 별도로 진행됩니다.
- 가결 시 대상자의 현재 연결과 자리를 제거하고 입장 화면으로 돌려보냅니다. 자동으로 재입장하지는 않지만, **접속** 버튼을 누르면 대기 시간 없이 같은 방에 다시 입장할 수 있습니다. 새 참가자로 들어오므로 진행 중인 라운드는 관전하고 다음 라운드부터 참여합니다.
- 강퇴는 방에서 잠시 내보내는 기능이며 재입장 차단이나 영구 제재가 아닙니다. 게임 호스트 자체를 종료하거나 서버 권한을 이전하지 않습니다.
- 전원이 퇴장하면 강퇴 투표·결과·제안 대기 시간을 초기화합니다. 이후 새로 입장한 사람에게 이전 강퇴 안내가 표시되지 않습니다.

## 서버 Origin 설정

직접 접속은 WebSocket 요청의 Host·프로토콜과 같은 Origin을 허용합니다. Electron UI는 `http://127.0.0.1:55510`부터 `55520`까지만 별도로 허용합니다.

HTTPS 리버스 프록시를 사용한다면 외부 Origin을 명시합니다. 쉼표로 여러 Origin을 지정할 수 있습니다. 경로나 마지막 슬래시 없이 작성합니다.

```powershell
$env:LIAR_ALLOWED_ORIGINS='https://liar.example.com'
npm run web
```

Origin 검사는 브라우저의 다른 출처 접속을 제한하는 장치이며 사용자 인증을 대신하지 않습니다. LAN 발견 프로토콜 버전을 2로 올렸으므로 Electron 참가자 모두 같은 버전을 사용해야 합니다.

## 검증

`npm test`에 관전·강퇴·반복 재접속·Origin 회귀 테스트와 같은 브라우저 컨텍스트의 여러 탭을 사용하는 UI 테스트를 포함했습니다. 실행 전 `npm ci`와 `npx playwright install chromium`이 필요합니다.
